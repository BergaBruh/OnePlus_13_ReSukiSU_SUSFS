# OP13 Global OOS16 6.6.118 GitHub Actions Build Plan

## Success criteria

1. One manual GitHub Actions workflow targets only OP13 Global OOS16 6.6.118.
2. OnePlus common/modules, AnyKernel3, ReSukiSU, and SUSFS use the fixed SHA
   revisions recorded in the design.
3. The existing multi-model workflow remains unchanged.
4. Static validation passes, the branch is pushed, and the manual workflow is
   dispatched and observed to upload a build artifact.

## Steps

1. Add a failing static test for the dedicated target, fixed revisions, and
   ReSukiSU setup script.
2. Add the target-specific config, manifest, and manual workflow.  Pass the
   config as JSON to the existing `build-kernel` composite action.
3. Make the composite action fetch ReSukiSU's setup script from the requested
   branch or commit, retaining `main` only as its empty-input default.
4. Run the static test and whitespace checks.  Commit and push only the new
   target workflow/config/manifest, test/docs, and surgical composite fix.
5. Dispatch the workflow on the pushed branch and use its artifact/logs as the
   release gate.  Fix only an observed workflow failure.

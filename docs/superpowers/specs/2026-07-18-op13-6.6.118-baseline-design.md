# OP13 6.6.118 Baseline Build Design

## Goal

Produce a reproducible, local, clean build of the OnePlus 13 (`dodge` / SM8750)
kernel source at Linux 6.6.118. This phase does not create a flashable package and
does not modify any phone image.

## Source Baseline

- Repository: `https://github.com/crdroidandroid/android_kernel_oneplus_sm8750.git`
- Commit: `d7067f0ef3dd7c9a48818c80f9cc4e34920e4f83`
- Device target: `sun`, 4 KiB page size
- Expected Linux version: `6.6.118`

This is an AOSP/custom-ROM kernel tree. It is not the same commit as the stock
OxygenOS 16.0.9 kernel (`2e6b9c3812c5`), so it must not be flashed on the device
as part of this phase.

## Deliverable

An isolated source checkout plus a build script that:

1. verifies the checked-out commit and `Makefile` version;
2. invokes the source tree's standard `sun` 4 KiB build configuration;
3. records the command, source commit, kernel release, and SHA-256 hashes of
   generated kernel artifacts;
4. fails before compiling if the source version is not exactly 6.6.118.

Build outputs and downloaded source remain ignored local artifacts. The tracked
repository changes are limited to the script, its automated validation, and
documentation.

## Safety and Validation

- No `fastboot`, `adb`, image repacking, or flashing commands are part of this
  phase.
- A test validates the script's source-identity guard before a real build runs.
- Successful completion requires a generated kernel image whose embedded release
  begins with `6.6.118` and a recorded SHA-256 digest.
- Failure to fetch dependencies or compile is reported as a build-environment or
  source-tree blocker; no version string is spoofed.

## Deferred Work

ReSukiSU, SUSFS, AnyKernel packaging, stock-OOS ABI comparison, vendor module
rebuilding, and device flashing are separate subsequent phases after this clean build
has succeeded.

# OnePlus 13 6.6.118 baseline build

This procedure builds a clean **kernel `Image` only** for OnePlus 13 (`sun`, SM8750) from a historical crDroid source checkpoint. It does not produce a stock-OxygenOS-flashable package.

## Fixed inputs

- Device context: CPH2653 Global, OxygenOS `16.0.9.401(EX01)`.
- Stock OTA KMI: `6.6.118-android15-8-g2e6b9c3812c5-ab15114928-4k`.
- Baseline source: `https://github.com/crdroidandroid/android_kernel_oneplus_sm8750.git` at `d7067f0ef3dd7c9a48818c80f9cc4e34920e4f83`.
- Required source version: `6.6.118`.
- OnePlus module tree: `https://github.com/OnePlusOSS/android_kernel_modules_and_devicetree_oneplus_sm8750.git` at `6fc9d867b7e58a290b275e91f3fbbdde82749bfa`.
- Android Clang: `r510928`, from `https://git.codelinaro.org/clo/la/kernelplatform/prebuilts-master/clang/host/linux-x86.git` at `b099698c583b8361ca771f3cc8d6af6f729f39b3`.

The source is not the unpublished OnePlus commit `g2e6b9c3812c5`. A successful build proves only that this pinned custom-ROM baseline compiles.

## Build target

The harness resolves the source's 4K `sun` configuration from these upstream source files, in this order:

1. `arch/arm64/configs/gki_defconfig`
2. `arch/arm64/configs/vendor/sun_perf.config`
3. `arch/arm64/configs/consolidate.fragment`
4. `arch/arm64/configs/vendor/sun_consolidate.config`

It then runs `olddefconfig`, requires `CONFIG_ARM64_4K_PAGES=y`, and invokes `make ... Image` with the pinned Android Clang. This intentionally does not invoke Kleaf packaging for `boot.img`, `init_boot.img`, `vendor_boot.img`, or `vendor_dlkm.img`.

## Run

All fetched files and outputs remain under `.op13-baseline/`, which is Git-ignored.

```bash
bash scripts/op13-baseline-build.sh preflight
bash scripts/op13-baseline-build.sh fetch-source
bash scripts/op13-baseline-build.sh fetch-modules
bash scripts/op13-baseline-build.sh fetch-toolchain
bash scripts/op13-baseline-build.sh build
```

`fetch-modules` creates `.op13-baseline/sm8750-modules -> modules/vendor`, the location expected by the source's Oplus symlinks. It does not prepare device-tree inputs, because this phase builds only `Image`.

`preflight` requires `git`, `make`, `bc`, `bison`, `flex`, `openssl`, `perl`, `python3`, `pahole`, `file`, `sha256sum`, `df`, `nproc`, and `tee`, plus at least 80 GiB free space. The harness applies `-Wno-error=incompatible-pointer-types-discards-qualifiers` only to host tools; the target kernel still uses the pinned Android Clang.

The expected image path is `.op13-baseline/out/sun-4k/arch/arm64/boot/Image`; the timestamped command log is under `.op13-baseline/logs/`.

## Safety boundary

Do not flash any output from this baseline phase. Do not patch KernelSU, ReSukiSU, or SUSFS into it yet. Do not replace images extracted from the OTA. The checked build reports `6.6.118-debug-gd7067f0ef3dd`, not the OTA's stock KMI; therefore it is deliberately unsuitable for a stock OxygenOS boot image. The next phase starts only after an exact stock-compatible source/layout has been established.
